# ⚔️ Pokémon Battle Notes

![Status](https://img.shields.io/badge/status-active-brightgreen) ![Versão](https://img.shields.io/badge/version-1.1-blue)

**Pokémon Battle Notes** é um aplicativo web para anotar e planejar batalhas Pokémon, criado para ajudar treinadores em desafios como o **Kaizo Ironmon**. Com ele, você pode registrar o HP, habilidade, movimentos e status do inimigo, além de salvar anotações para consultar depois.

---

## ✨ Funcionalidades

- **Anotações de Batalha**: Registre o HP, status, habilidade e movimentos do Pokémon inimigo.
- **Organização**: Salve anotações com meta e observações.
- **Personalização**: Alterne entre modo claro e escuro, ajuste o tamanho da fonte e o brilho.
- **Gerenciamento de Dados**: Exporte e importe suas anotações para nunca perder seus registros.
- **Interface Intuitiva**: Busque por qualquer Pokémon (mais de 1000) ou movimento rapidamente.
- **Modo Shiny**: Visualize a versão shiny dos Pokémon.
